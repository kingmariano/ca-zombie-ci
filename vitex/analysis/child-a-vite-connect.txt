# ViteConnect Bridge Server

Fork from [node-walletconnect-bridge](https://github.com/WalletConnect/node-walletconnect-bridge)

## Development

```bash
yarn

yarn dev
```

## Production

### Using NPM

1. Build

```bash
yarn build
```

2. Production

```bash
yarn start
```

3. Check

```bash
$ curl http://localhost:5000/hello
> Hello World, this is WalletConnect v1.0.0-beta
```

### Using Docker

1. Build the container with:

```bash
yarn build:docker
```

2. Run the container with:

```bash
docker run -p 5000:5000 vitelabs/vite-connect-server
```

3. Check:

```bash
$ curl http://localhost:5000/hello
> Hello World, this is WalletConnect v1.0.0-beta
```

# [vite.org](https://vite.org)

Vite is a zero-fee, lightning-fast blockchain for the decentralized economy. Build Web3 without giving up the free and fast features of Web2.

## Setup

Make sure to install the dependencies:

```bash
# yarn
yarn install

# npm
npm install

# pnpm
pnpm install
```

## Development Server

Start the development server on `http://localhost:3000`

```bash
npm run dev
```

## Production

Build the application for production:

```bash
npm run build
```

Locally preview production build:

```bash
npm run preview
```
